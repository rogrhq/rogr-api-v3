1. DOMAIN EXTRACTION METHOD
--------------------------------------------------------------------------------
Location: intelligence/content/fullread.py, lines 236-241

Code:
```python
p = urlparse(url or "")
host = (p.hostname or "").lower()

# Remove www. prefix for matching
if host.startswith('www.'):
    host = host[4:]
```

Behavior:
- Uses urllib.parse.urlparse (Python standard library)
- Extracts p.hostname property (full hostname with ALL subdomains)
- Converts to lowercase
- Removes ONLY "www." prefix
- Does NOT remove other subdomains

Examples:
- https://en.wikipedia.org/wiki/Boiling_point → "en.wikipedia.org"
- https://www.wikipedia.org/ → "wikipedia.org" (www. removed)
- https://pubs.acs.org/doi/10.1021/... → "pubs.acs.org"
- https://masterorganicchemistry.com/... → "masterorganicchemistry.com"

```python
def extract_domain(url):
    """Extract clean domain from URL"""
    try:
        parsed = urlparse(url)
        domain = parsed.netloc.lower()
        # Remove www. prefix
        if domain.startswith('www.'):
            domain = domain[4:]
        return domain
    except:
        return ''
```

Note: Uses .netloc instead of .hostname (same result in practice)

SYSTEMATIC PATTERN:
================================================================================

Common pattern across all 3 issues:

1. SUBDOMAIN PRESERVATION
   - Domain extraction keeps ALL subdomains except "www."
   - Examples: en., pubs., mobile., m., www2., etc. all preserved
   - This breaks matching for any subdomain variations

2. EXACT MATCHING REQUIREMENT
   - Whitelist matching uses exact string equality
   - No fuzzy matching, no partial matching, no subdomain stripping
   - "en.wikipedia.org" ≠ "wikipedia.org" → no match

3. SMALL WHITELIST SIZE
   - Only 10 domains in _ESTABLISHED_REFERENCES
   - Many authoritative sources not included (ACS, JSTOR, IEEE, etc.)
   - No wildcard or pattern-based matching

4. LIMITED FALLBACK DETECTION
   - .gov domains: Works (suffix match)
   - .edu domains: Works (suffix match)
   - Peer-reviewed: Works only if text contains phrase "peer-reviewed"
   - No URL pattern recognition (e.g., /doi/, /article/, pubs., journals.)
